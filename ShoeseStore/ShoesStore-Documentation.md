# Shoes Store Website

## 📌 Overview

A modern e-commerce website for a shoe store, built with **HTML**, **CSS**, and **JavaScript**. The website offers a comprehensive shopping experience with product browsing, user account management, and contact features.

---

## 🚀 Features

### 🔸 Navigation
* Responsive navigation menu
* Category filtering
* Search functionality

### 🔸 Product Display
* Product image galleries
* Detailed product information
* Price display
* Size selection

### 🔸 User Account
* Registration system
* Form validation
* Account management

### 🔸 Contact Features
* Contact form
* Social media links
* Location information

---

## 🎨 Design Elements
* Modern layout
* Product image showcases
* Interactive elements
* Social media integration
* Payment method icons

---

## 📁 File Structure

```
/ShoeseStore

├── home.css           # Main styles
├── Regestration.js    # Registration logic

```
