# Quiz Application

## 📌 Overview

An interactive quiz application built with **HTML**, **CSS**, and **JavaScript**. The application provides a user-friendly interface for taking quizzes and getting immediate feedback.

---

## 🚀 Features

### 🔸 Quiz Interface
* Clean question display
* Multiple choice answers
* Interactive response selection
* Score tracking

### 🔸 Functionality
* Question progression
* Answer validation
* Score calculation
* Final results display

### 🔸 Visual Design
* Responsive layout
* Clean typography
* Visual feedback for selections
* Progress indication

---

## 🎨 Styling Features
* Modern color scheme
* Responsive design
* Interactive button states
* Clear visual hierarchy
